## Guide / Thần Chú compact method-card variant · S116 + S118 PO decision
- **Status:** Specific PO-accepted visual intent, NOT blanket G2 signoff. The `#page-guide #method-cards` grid is **two equal columns on phones ≤640px**, rather than the v0.3 auto-fit 220px rule that regressed it to one. Preserve 13 methods, mentor, filters/search, four study modes, full academic name, and card-button → detail route.
- **Anatomy:** compact method icon → category/T-ID kicker → full Vietnamese title (never ellipsis) → English academic name (wrap) → **two-line purpose teaser** (full explanation in detail) → `CHÚ GIẢI →` anchored to bottom. Entire tile is the button.
- **Mobile geometry:** **Exact S118 PO-approved 18px horizontal / 20px vertical gap** (narrow ≤360px: **14px horizontal / 18px vertical**), 11×10px tile inset (narrow: 10×9px), grid padding 3/6/8/3px (narrow: 3/5/8/2px), top 18px. These are documented MICRO-GEOMETRY exceptions to generic 4px token normalization, with preserved two-column intent and cleaner 4px rhythm. Essential supporting text is **14/20px**, title **20/28px**, no hiding method names.
- **Critical regression check:** real computed grid at **320/375/390/402/600/640** must report 2 tracks, first two cards share a row, tap targets stay usable, no horizontal overflow and every card reaches the correct detail. **Tablet/desktop** use adaptive columns.
- **Sources:** [S116 accepted 2-up mobile](https://app.notion.com/p/41b6cf6db72a814a8dc6d741386c5bc7); [S118 PO spacing correction](https://app.notion.com/p/41b6cf6db72a8106a821edececd098fd). Do **not** drop this variant during further token/component consolidation.

## Visual design rules (decisions vs QA)
- **PO-specific visual exceptions:** even though S81 baseline generally asks square controls, the latest header/bottom **active icon background is intentionally an oval sand pill**, and the separate **Lão Lý chat is a rounded speech bubble**. Do **not** run blanket `border-radius:0` resets on these.
- **Touch exception risk:** source currently contains PO-requested pinch-zoom locking; this remains an **accessibility concern**, not WCAG acceptance. Accessibility review must record that risk rather than pretending all gestures/zoom are supported.
- **iPhone Safari square tap flash regression:** native tap highlight and touch-hover overlays have reappeared in the past. Test visually on device; source presence of `-webkit-tap-highlight-color` is only a smoke check.
- **Latest state wins:** if Notion or new PO feedback differs from the above, update this contract **and** every affected implementation/screenshot fixture together. Never quietly make the docs say something old.

## Adoption pattern for a new screen
1. Choose an existing component + variant from this table.
2. Reuse its spacing/geometry/color/semantic state (not a copy-pasted one-off CSS block).
3. Define exceptional behavior with a design decision link and note in this table.
4. Check every other instance of that component before merging.
5. Record status as **observed**, **PO-accepted specific**, **pending**, or **rejected/deprecated**.

## v0.3 typography and spacing — shared implementation rule
- **Runtime CSS:** generated `site/assets/design-tokens.css` owns all basic/semantic palette, type and spatial values; `site/assets/ui-foundations.css` is the canonical component-role layer (loaded last), not a new framework.
- **Default:** 16px/24px reading text, 14px/20px essential supporting text, 12px/16px only metadata; Crimson Text editorial headings 24/32 and up. All line heights are multiples of 4px.
- **Grid:** space tokens 0/4/8/12/16/20/24/32/40/48/64/80/96 CSS px. Every new padding, margin and gap must use a token or a value divisible by 4. Touch target goal 48px.
- **Guide:** S116/S118 Human PO decision wins: two compact method tiles per row at phone ≤640px with S118 exact 18/20px (narrow 14/18px) gaps; full title/academic name, 2-line teaser only, complete explanation in detail.
- **Scope:** Home, Catalog, Guide, Library, Research, Search, Capture, Settings, Lão Lý and published Wave1 lesson families all share type/spacing roles. Preserve special artwork geometry, selected sand pill and speech bubble.
- **Limit:** `site/assets/li-layout.css` preserves art-sensitive, legacy selector/breakpoint rules, including some remaining unmapped contextual colors and unitless line heights. All tracked numeric margin/padding/gap literals in app and Wave1 CSS are on the 4px grid in the current static audit. Browser smoke checks actual computed styles at seven widths, not physical iPhone or G2 acceptance. See [v0.3 report](audits/2026-11-18-css-refactor-v03.md).
